PowerWiki · v1.6.2

把 Git 仓库变成知识库

PowerWiki 把仓库里的 Markdown 和 HTML 变成可浏览、可分享的站点： 左侧查找文档，右侧定位章节，中间阅读正文。没有数据库，也没有后台， Git 仓库就是唯一的数据源——本站正是这样一个仓库。

03

核心能力

Markdown 与 HTML 一起收录

两种文章共用目录、复制、原始视图、分享短链、阅读数和 SEO 标签，不需要两套站点。

隔离沙箱

HTML 页面可以跑完整脚本与样式，但拿不到站点的 Cookie、localStorage 和同源接口。

双侧导航

左侧按仓库目录查找文档，右侧跟随当前文章章节，长文档也能快速定位。

沉浸式阅读

HTML 文章原地展开为全屏画布，Esc 退出；工具条另有全屏入口，可独立打开完整页面。

稳定地址与 SEO

slug 与 aliases 让链接在文件移动后依然有效；canonical、Open Graph、RSS 与 sitemap 共用同一地址。

Git 即数据源

定时拉取仓库，提交即发布；内容变化自动失效缓存，不需要数据库或管理后台。

快速开始

准备一个 Git 仓库，复制配置，一条命令启动。Node.js 22 LTS 或 Docker 均可。

# 克隆并启动
git clone https://github.com/steven-ld/PowerWiki.git
cd PowerWiki

cp config.example.json config.json
# 编辑 config.json，填入您的仓库地址

docker-compose up -d
# 打开 http://localhost:3150
