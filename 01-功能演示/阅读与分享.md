# 阅读与分享

用下面这段内容体验文章工具栏与代码复制。

## 复制文章与代码

文章顶部的「复制」按钮复制整篇 Markdown 原文；代码块的复制按钮只复制对应代码。操作需要浏览器允许剪贴板访问，建议通过 HTTPS 或 localhost 打开。

```javascript
const greeting = 'Hello, PowerWiki!';
console.log(greeting);
```

## 查看原始 Markdown

点击「原始」查看本文源码，再点击「渲染」返回排版后的文章。可以对照标题、列表、代码和引用的写法。

> 写作仍在自己的编辑器和 Git 仓库中完成；原始视图用于阅读源码。

## 分享短链

点击「分享」复制短链，在新标签页打开，确认进入同一篇文章。短链根据文章路径生成；同一路径保持稳定，移动或重命名文章后应重新分享。

## 暗夜模式与章节导航

点击顶部主题按钮切换浅色或深色。桌面端通过右侧目录定位章节，窄屏通过左上角菜单按钮查找文档。

![暗夜模式下的阅读界面](/images/dark-mode.jpg)

## 自检清单

- 复制全文后能粘贴出 Markdown 源码。
- 原始 / 渲染来回切换后，代码复制仍可使用。
- 分享短链能进入相同文章。
- 切换到没有标题目录的文章后，不保留上一篇的目录。
